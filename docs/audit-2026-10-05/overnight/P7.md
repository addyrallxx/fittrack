## Decisions
- Remove the zoom lock from the viewport meta, keep `touch-action: manipulation`, and add `interactive-widget=resizes-content`.
- Every text and number input renders at 16 px or larger (iOS Safari zooms on focus below 16 px).
- `inputmode` matches the value (integers `numeric`, decimals `decimal`, including fractional fl oz), `enterkeyhint` set deliberately, `autocomplete="off"` on numbers, a real label or `aria-label` on every field. Reps and load ranges stay text where they are text today.
- When a field inside a sheet gains focus, keep it and its submit button visible above the keyboard using `visualViewport` (scroll the dialog content, never move the page behind it).
- Enter advances to the next field or submits exactly once; validation errors keep focus and the draft.
